Usage: android device [-h] [COMMAND]
Manage Android devices. Mirror connected devices or emulators in a desktop
window and manage remote physical device reservations

Options:
  -h, --help       Shows the help message for the specified command

android options:
      --sdk=PARAM  Path to the Android SDK
  -v, --verbose    Enable verbose output for troubleshooting
  -V, --version    Print version information and exit
Commands:
  hub     Launches a desktop window for real-time screen mirroring and
          interactive control of a connected Android device or emulator
  remote  Manage remote physical devices. Includes commands to list, reserve,
          connect to, and manage remote device reservations
