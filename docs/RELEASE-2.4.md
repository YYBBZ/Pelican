# Pelican 2.4 交付说明

- `/workspace/Pelican.apk` 为最终签名安装包；2.4 / versionCode 8 / app.pelican.monitor。
- 沿用2.3签名，支持覆盖安装。建议先导出备份，不要卸载。
- 旧历史会在后台本地重判，完成信息可在「设置→输入异常筛查与旧历史重判」查看；资料不足明确标注。
- 新版自定义题目顺序与进度按线路保存；旧线路初始化为原题目一条，编辑顺序表可再添加其余题目。
- 输入「注入」标识是疑似筛查结果，不是确证。

## 验证口径
- 253项本地检查：16原有回归、221新版规则与参数/解析/顺序/迁移逻辑检查、16隔离回环HTTP字节检查。
- 16组Android JVM框架验收：实际引擎10张、11次请求=10次补试、真实拖动事件、自定义题增加/排序、七档和预算限制、监控/编辑/执行下限一致、输入异常通知隔离、详情五行、真实SQLite/JDBC迁移/删除/备份往返、13个真实输出AndroidSVG解析回放等。
- 上述Android运行检查为Robolectric SDK28、ARM环境上的本地模拟；UI测试用明确标记的内存仓储，数据库测试运行真实Store SQL并用SQLite/JDBC桥接。不是手机原生SQLite或真机测试。
- 真实接口：模型列表成功（10个）；13次必要短生成全部完整返回，每次上限512；覆盖Chat自动档10次、xhigh/max各1次及Responses自动档1次。其中3次命中输入异常规则。未启动定时监控。
- v2/v3签名、旧新证书一致、ZIP完整性、对齐和密钥/测试代码排除检查通过。
- Android16 JVM兼容尝试受Robolectric Linux aarch64原生库缺失阻塞；不得宣称该项通过。
- 尚未在用户小米Android16上安装验收，也未做实际桌面渲染/后台长时间运行验证。

详细结果见 verification/final-result.json 和 verification/v2.4/ 各项日志。测试密钥临时文件已删除。
