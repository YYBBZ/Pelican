# Pelican

让模型定时画同一只鹈鹕，画得一次比一次糊，那这条线大概就开始降智了。

## 为什么写这个

用中转站的人应该都碰上过：前几天好好的，今天突然变笨。回答短了、绕了，稍微复杂点的活就开始糊弄。可你去查接口，200，一切正常。

问题多半出在号池。中转站把一堆账号拼起来用，那些账号的 IP 干不干净，它自己都未必清楚。IP 一脏，模型状态就跟着掉。而这种掉法不报错、不写日志、不告警，你只能凭感觉：今天怎么这么笨。

感觉这东西靠不住。我就想要个数。

## 怎么测

题是画画。让它用 SVG 画鹈鹕——英文的、中文的、土星环上的，还有加菲猫。

为什么挑画画？因为这事糊弄不过去。你问它 1+1，降智的模型照样答对；但让它画一只有细节的鹈鹕，脑子不清楚的时候立刻露馅：画一半断了、退化成几个色块、或者干脆写俩字"鹈鹕"交差。

拿回来的东西在本地拆开看：节点多少、线条总长、用了几种颜色，算出一个 0–100 的分。不上传，也不发出去让别人算。

## 多少分算不正常

一次低了不算数，模型本来就抖。所以是让它跟自己比。

最近 5 次成功结果，取中位数，打个八折，再乘一个倍率（默认 0.9），这条就是及格线。低于它标可疑。嫌麻烦也可以手填一个固定分数线。

结果分四种：PASS 正常，SUSPECT 可疑，ERROR 返回有问题，FAIL 请求压根没成。

编辑页、监控页、历史记录用的是同一个算式同一个值，不会出现"编辑时显示 72 分及格，实际按 80 分判"这种破事。

## 它会偷懒，得防着

模型能偷懒的招数就那几种，我一个个盯着：

- 塞一张位图进去，假装是画的
- 不打形状，直接写"这是一只鹈鹕"
- 引用外部链接，等于外包给别人画
- 里面藏脚本

中一条就判 ERROR，不进基线，也不污染后面的分数。

还有更阴的：有些中转站会把你的请求悄悄转到便宜的模型上。所以每次都会对一下它回显的模型名，对不上也算 ERROR。

## 顺便看看有没有被动手脚

中间人是有机会在请求里加东西的。所以每轮都会拿返回的 token 数和本地估的比一比，差太多就标一个蓝色的「注入」。

注意这是"疑似"，不是抓到实证。所以它单独归一类，不弹通知、不算进连续异常。详情里会把估算值、实际值、差多少、命中了哪条规则全列出来，你自己判断。

## 多条线，各算各的

一条线路就是一套自己的东西：地址、key、模型、间隔、题目顺序、基线。

关键是基线别混着算。九块钱的模型和旗舰模型正常水平差着量级，混一起等于全错。支持 OpenAI 的 Chat、Responses，还有 Anthropic 的 Messages，模型列表能直接拉。

## 还有什么

- 能后台定时跑，间隔自己定
- 题目内置四道，也能自己加；顺序按线路存，能拖着挪；下一轮排在第一位
- 一轮可以跑 1–99 个样本，没成还能补试，最多 20 次（补太多会提醒你在重复花钱）
- 思考强度七档，中英双标；选 auto 就不传参数
- 趋势图是拿 SVG 画的，能缩放、能横屏
- 每一轮的原始 SVG 都留着，能导出。不信分数就自己看
- 只在连续出问题的时候才通知你，单次波动不吵
- 整个库能备份能恢复
- 老版本的历史升级后本地重判，不重新请求，不花钱

## 数据在哪

都在你手机上。除了你自己填的那个地址，App 不连别的地方，没有上报，没有云同步，连注册登录都没有。

## 装

去 [Releases](https://github.com/YYBBZ/Pelican/releases) 下 APK，5.1 MiB 左右。

包名 `app.pelican.monitor`，versionCode 8，Android 8 以上能装。签名跟 2.3 一样，直接覆盖装就行，历史、线路、基线都还在。不过装之前还是先导一份备份，别卸载。

## 自己编一个

```bash
bash scripts/build.sh
```

要 JDK 17、aapt2、D8/R8、zipalign、apksigner，Java API 35，目标 API 34。依赖 jar 都在 `app/libs`，许可文件在 `app/src/main/assets`。签名私钥没放仓库里。

## 说明白点

253 项本地检查和 16 组 Android JVM / SQLite 验收过了，13 次真实短生成也都完整返回。

Android 16 那项卡在 Robolectric 缺 Linux ARM 原生库上，没算通过。真机安装验收还没做，桌面上的实际渲染、长时间后台跑也都没验过。

最后一句：这玩意儿给的是趋势和疑点，不是判决书。分低可能是降智，也可能它今天就是不想画。
